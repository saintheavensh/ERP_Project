# Book 12 - Engineering Standards

This directory defines the rules of collaboration for the development team. To build a robust ERP, developers must work in absolute synchronization without overwriting each other's code.

## The Developer Handbook
This is the final rulebook for anyone touching the source code of the Universal Service ERP.

## Specification Documents

* **[B12-ENG-001 Git Branching Strategy](B12-ENG-001%20Git%20Branching%20Strategy.md):** Defines how developers should branch their work off the main codebase.
* **[B12-ENG-002 Pull Request Guidelines](B12-ENG-002%20Pull%20Request%20Guidelines.md):** Defines the strict Code Review process.
* **[B12-ENG-003 Coding Conventions](B12-ENG-003%20Coding%20Conventions.md):** Defines naming conventions and automated linting tools to keep the code clean.
