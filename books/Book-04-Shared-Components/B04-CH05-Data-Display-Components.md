# Form Components

## Purpose

This document defines reusable form components.

---

# Standard Form Components

The platform provides:

- Text Input
- Number Input
- Password Input
- Text Area
- Select
- Multi Select
- Checkbox
- Radio Button
- Switch
- Date Picker
- Time Picker
- Date-Time Picker
- File Upload
- Image Upload
- Search Input
- Auto Complete
- Rich Text Editor

---

# Validation

Form Components should support:

- Required validation
- Length validation
- Pattern validation
- Numeric validation
- Date validation
- Custom validation

Validation messages should be presented consistently across the platform.

---

# Rules

Form Components:

- Must support disabled state.
- Must support read-only state.
- Must support validation feedback.
- Must be keyboard accessible.
- Must remain independent of business logic.

---

# Summary

Form Components provide a standardized way to collect and validate user input.
