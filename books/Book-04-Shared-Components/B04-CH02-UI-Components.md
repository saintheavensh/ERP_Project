# UI Components

## Purpose

This document defines the reusable user interface components used throughout the platform.

---

# Overview

UI Components are generic building blocks used to construct user interfaces.

They must remain independent of business modules.

---

# Standard Components

The platform provides reusable components including:

- Button
- Icon Button
- Text
- Badge
- Avatar
- Chip
- Divider
- Card
- Tooltip
- Spinner
- Skeleton Loader
- Progress Bar
- Progress Ring

Additional components may be added when required.

---

# Rules

UI Components must:

- Be reusable.
- Be configurable.
- Support accessibility.
- Follow the design system.
- Remain free of business logic.

---

# Summary

UI Components provide a consistent visual language across the platform.
