# Best Practices

## Principles

- Write clearly.
- Keep documents focused.
- Avoid duplication.
- Keep terminology consistent.
- Update documentation before implementation.
- Prefer references over copying.
- Keep documents modular.
- Keep documentation simple.

---

# Common Mistakes

Avoid:

- Ambiguous language.
- Missing references.
- Multiple names for the same concept.
- Large documents covering unrelated topics.
- Outdated documentation.

---

# Summary

Following these practices keeps the documentation consistent, maintainable, and scalable.
