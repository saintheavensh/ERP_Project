# Change Management

## Purpose

This document defines how documentation changes are managed.

---

# Goals

- Keep documentation consistent.
- Prevent conflicting changes.

---

# Rules

- Identify the change.
- Update the authoritative document.
- Update affected references.
- Commit changes.
- Continue implementation only after documentation is updated.

---

# Summary

Documentation must always reflect the current system design.
