# Documentation Lifecycle

## Purpose

This document defines the lifecycle of every document.

---

# Lifecycle

1. Requirement
2. Specification
3. Review
4. Implementation
5. Maintenance
6. Revision

---

# Rules

- Documentation precedes implementation.
- Documentation evolves with the system.
- Obsolete documentation must be updated or removed.

---

# Summary

Every document follows the same lifecycle.
