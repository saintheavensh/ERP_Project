# Documentation Quality Checklist

## Checklist

Before a document is complete, verify:

- Purpose is defined.
- Goals are defined.
- Non-Goals are defined.
- Terminology is consistent.
- No duplicated information.
- References are valid.
- Grammar is correct.
- Formatting is consistent.
- Markdown renders correctly.

---

# Summary

Every document should pass this checklist before being considered complete.
