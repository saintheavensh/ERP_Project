# Cross Reference Rules

## Purpose

This document defines how documents should reference one another.

---

# Goals

- Prevent duplicate information.
- Maintain Single Source of Truth (SSOT).
- Improve navigation.

---

# Non-Goals

This document does not define document structure or writing standards.

---

# Rules

## Rule 1

Reference documents instead of copying their contents.

---

## Rule 2

Every reference must point to the authoritative document.

---

## Rule 3

Do not duplicate business rules across multiple documents.

---

## Rule 4

Cross references should be relevant.

Avoid unnecessary references.

---

## Rule 5

If a referenced document changes, dependent documents should be reviewed.

---

# Example

Correct

Purchase API

References:

- Purchase Workflow
- Purchase Database

Incorrect

Purchase API contains duplicated workflow and database documentation.
