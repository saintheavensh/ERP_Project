# Version Control

## Purpose

This document defines version control practices for the documentation repository.

---

# Goals

- Track changes.
- Preserve history.
- Support collaboration.

---

# Rules

- Git is the official version control system.
- Commit related changes together.
- Write meaningful commit messages.
- Never overwrite history without agreement.
- Keep the main branch stable.

---

# Commit Message Examples

```
docs: add inventory workflow

docs: update purchase specification

docs: fix API documentation
```

---

# Summary

All documentation changes must be tracked through Git.
