# Constraints

## Purpose

This document defines the constraints affecting the project.

---

# Constraints

- Development must follow the approved documentation.
- Core modules should remain independent.
- Business rules must remain technology-independent whenever possible.
- Changes should preserve backward compatibility whenever practical.
- New modules should integrate without modifying the existing core.
- Documentation must remain synchronized with implementation.

---

# Summary

These constraints help maintain consistency and long-term maintainability.
