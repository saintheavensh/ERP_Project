# Project Glossary

## Purpose

This document defines the primary business terms used throughout the Universal Service ERP project.

---

# Terms

| Term | Definition |
|------|------------|
| Customer | A person or organization receiving services. |
| Supplier | A person or organization providing goods or services. |
| Device | The customer's equipment submitted for service. |
| Technician | A user responsible for diagnosing and repairing devices. |
| Service Order | A record of a service request. |
| Product | An item sold or used by the business. |
| Inventory | The collection of products managed by the system. |
| Batch | A quantity of inventory received in a single purchase. |
| Purchase Order | A document used to purchase products from suppliers. |
| Sales Order | A document used to record product sales. |
| Invoice | A financial document issued for a transaction. |
| Dashboard | A page displaying business information and metrics. |
| Module | An independent functional area of the platform. |
| Core Platform | Shared functionality used by all modules. |
| Widget | A reusable dashboard component displaying specific information. |

---

# Summary

All documentation should use these terms consistently.
