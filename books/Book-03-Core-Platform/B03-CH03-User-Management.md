# User Management

## Purpose

This document defines how user accounts are managed.

---

# Responsibilities

The User Management service is responsible for:

- Create user
- Update user
- Disable user
- Activate user
- Reset password
- Assign roles
- Manage user profile
- Manage account status

---

# User Information

A user account may contain:

- User ID
- Username
- Full Name
- Email
- Phone Number
- Status
- Assigned Roles
- Assigned Branches
- Preferences

---

# Rules

- Every user must have a unique account.
- User information should be centrally managed.
- Business modules reference users but do not own user accounts.

---

# Summary

User Management provides centralized administration of platform users.
